VelCustom's — электронная NFC-визитка в неоновом стиле логотипа

Файлы:
- index.html — страница визитки
- logo.png — предоставленный логотип
- workshop-bike.png — изображение мастерской для hero-блока
- velcustoms.vcf — контакт для сохранения в телефон

Бесплатная публикация через GitHub Pages:
1. Создайте публичный репозиторий на https://github.com/
2. Загрузите все четыре файла в корень репозитория.
3. Откройте Settings → Pages.
4. Выберите Deploy from a branch, ветку main и папку /(root), затем Save.
5. После публикации откройте URL, который покажет GitHub Pages, и проверьте кнопки.

Запись на NFC:
1. Скопируйте опубликованный URL страницы.
2. В NFC Tools выберите Write → Add a record → URL/URI.
3. Вставьте URL, нажмите Write и приложите NTAG213/215.
4. Проверьте метку телефоном.

На метке хранится ссылка, а не сама страница. Все файлы должны быть опубликованы в одном каталоге.
